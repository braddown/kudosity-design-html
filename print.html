Print and placement.

The style guide is a print document. Digital keeps hex. Print uses these CMYK values and millimetre sizes. Same three marks, same clear space (O-height). Don’t recolour or warp.

Print type

Optical kerning. Tracking 0 on heads, +10 on body. Sentence case – never all-caps or all-lowercase.

Marks

Style guide names map to ours: Primary = wordmark, Primary-TAG = tagline lockup, Primary-Special use = O device.

Primary

Wordmark

Default on stationery, tees, totes and pens – if it holds 20 mm.

Primary-TAG

Tagline lockup

Where the brand needs to explain itself once. Not a running header.

Primary-Special use

O device

The guide’s special-use mark. Right choice for a coffee cup.

Placement

Style guide examples as cards, not product shots. Pick the mark that fits. Keep O-height of clear space. Don’t recolour or warp the artwork around a seam.

Stationery

Business card, A4, envelope DL

Pick the mark that fits the format. Keep O-height of clear space on every side.

Uniform

Tees

Follow the uniform placement in the guide. Don’t warp the mark around a seam.

Gift

Tote

Large horizontal wordmark. Primary, not the O, not a rebuilt type lockup.

Special use

Coffee cup

The O device is the right special-use mark. The guide says so.

Small goods

Pens

Wordmark if it holds 20 mm. Otherwise don’t force it.

Don’ts

The artwork is supplied. Place it. Don’t rebuild it from Noto Sans.

01

Don’t recolour the artwork

Never recolour, outline, or add a shadow, glow or bevel. The supplied file is the mark.

02

Don’t distort or warp it around a seam

Place it flat. A wrap, a curve or a squash is a different drawing – and it isn’t ours.

03

Don’t go below 20 mm in print or 140 px digital

If it doesn’t hold the floor, don’t force it. Use a different mark, or don’t use one.

04

Corporate register uses navy

Corporate / regulation announcements use navy #002A66 (trust, stability). That’s the only voice rule in this style guide.
